# Workout App PWA Demo

A tiny install-proof workout Progressive Web App for testing on iPhone.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static file server.

## Install on iPhone

After GitHub Pages is enabled/deployed:

1. Open the GitHub Pages URL in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Launch the app from the new icon.
5. Turn on Airplane Mode and reopen it to confirm the cached shell loads.
